# Importação de BIOS (v1.3)

O instalador **não inclui BIOS de PS2**. Para utilizá-lo, cada jogador deverá importar arquivos que tenha obtido legalmente e tenha direito de utilizar. Não distribua dumps proprietários sem autorização.

## Como importar

1. Extraia o arquivo `bios.rar` no seu próprio computador.
2. No Game Server Desktop, vá em **Configurações → Importar minha BIOS**.
3. Selecione **Selecionar pasta** e indique a pasta extraída.
4. O aplicativo copiará arquivos `.bin`, `.rom`, `.rom1`, `.rom2`, `.erom`, `.nvm` e `.mec` para uma pasta `bios` ao lado do executável PCSX2 configurado (sem substituir arquivos existentes).
5. Abra as configurações do PCSX2, confira a pasta BIOS e escolha uma BIOS reconhecida.

Os arquivos enviados continham modelos SCPH-10000, SCPH-39001, SCPH-70004 e 30004R PAL. O código não valida se um dump é autêntico ou funcional.

**Atenção:** uma instalação do PCSX2 com diretório protegido pode impedir a gravação na pasta próxima ao executável. Nesse caso, configure o PCSX2 para usar uma pasta de BIOS gravável.
